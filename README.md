# 📚 Machine Learning & NLP Research Summary

This document summarizes multiple mini-projects and research experiments conducted as part of my work in Machine Learning and NLP. The experiments covered a variety of tasks including Natural Language Processing, Exploratory Data Analysis (EDA), supervised and unsupervised learning, as well as data cleaning and preprocessing techniques.

---

## 🧠 1. NLP on NF-UNSW-NB15 Dataset (Versions 1 & 2)
- Performed Natural Language Processing tasks on both Version 1 and Version 2 of the **NF-UNSW-NB15 dataset**.
- Focused on analyzing and extracting meaningful insights from network traffic and flow-based security data.
- Applied preprocessing, tokenization, and feature engineering to prepare the text-based network data for downstream tasks.

---

## 📊 2. Exploratory Data Analysis (EDA) on CO₂ Emission Dataset
- Conducted a **comprehensive EDA** on a dataset related to **CO₂ emissions**.
- Analyzed correlations between fuel consumption, engine size, vehicle type, and emission levels.
- Visualized trends and distributions using `seaborn` and `matplotlib`.

---

## 🧪 3. Classification & Clustering Research Experiments
### 🔍 Objective:
To experiment with different classification and clustering techniques and evaluate how clustering impacts classification performance.

### 🔨 Classification Algorithms Used:
- **Decision Tree**
- **K-Nearest Neighbors (KNN)**
- **Support Vector Machine (SVM - Linear & Non-linear)**
- **Gaussian Naive Bayes**
- **Multi-Layer Perceptron (MLP)**

### 🧩 Clustering Algorithms Used:
- **K-Means**
- **K-Medoids**
- **Hierarchical Clustering**
- **DBSCAN**

### 🔁 Evaluation Strategy:
- Performed classification on original and **clustered datasets**.
- Evaluated both **with and without K-Fold cross-validation**.
- Compared performance using metrics such as **accuracy**, **precision**, **recall**, and **F1-score**.

---

## 🍄 4. Decision Tree on Mushroom Dataset
- Applied **Decision Tree classification** on the **Mushroom dataset**.
- Built a model to predict whether a mushroom is **edible or poisonous** based on physical characteristics.
- Evaluated the model using classification metrics and visualized the decision tree structure.

---

## 🦠 5. COVID-19 Dataset: Handling Missing Values & Outliers
- Focused on **data cleaning and preprocessing** using a COVID-19 dataset.
- Handled:
  - **Missing values** using imputation techniques
  - **Outliers** using statistical and visual detection methods (IQR, z-score)
- Prepared the dataset for further analysis and modeling.
